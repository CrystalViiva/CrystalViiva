## Featured Project — AssetFlow

**AssetFlow** is a production-oriented Fixed Asset Management System covering the asset lifecycle from acquisition and capitalization through depreciation, custody, transfers, maintenance, physical verification, assurance, reporting, and disposal.

### Engineering highlights

- Django REST Framework backend with PostgreSQL
- React + TypeScript frontend
- Exact Decimal-based fixed-asset accounting
- IAS 16-aligned straight-line depreciation workflows
- Transaction-safe lifecycle operations and concurrency controls
- Organization-scoped RBAC and department-level authorization
- Physical asset verification and deterministic assurance workflows
- Immutable report snapshots and durable CSV/JSON exports
- Private evidence storage with integrity verification
- Celery + Redis background processing
- Airflow extraction and PySpark analytics pipeline
- 6 curated analytical marts
- Full-system release gate covering accounting, security, tenancy, and lifecycle invariants

**Tech:** Python · Django · Django REST Framework · PostgreSQL · React · TypeScript · Celery · Redis · Airflow · PySpark · Docker
